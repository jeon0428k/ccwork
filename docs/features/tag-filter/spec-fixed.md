# 태그 필터링 — 확정 요구사항 (spec-fixed)

> 단계 1(요구사항 인터뷰) 산출물. 이 문서가 확정되면 PRD 작성으로 넘어간다.

## 개요

노트 목록을 **태그로 좁혀 보는** 기능. 사이드바 상단에 현재 노트들이 가진 태그를 칩으로
나열하고, 칩을 토글해 선택한 태그(OR 조합)에 해당하는 노트만 목록에 보여준다.
필터는 클라이언트 측 인메모리 연산이며 서버/저장소 변경은 없다.

## Primary User

노트를 여러 개 쌓아 둔 사용자가 특정 주제(태그)의 노트만 빠르게 추려 보려는 상황.

## 최소 동작 시나리오 (3)

1. **단일 태그 필터**: 사이드바 상단 "work" 칩을 클릭 → 목록이 work 태그를 가진 노트만 표시.
2. **다중 태그 OR**: "work"에 더해 "idea" 칩도 클릭 → work **또는** idea를 가진 노트 표시.
3. **필터 해제**: 켜진 칩을 다시 클릭하면 해제. 모든 칩을 끄면 전체 노트로 복귀.

## 확정 결정 사항

| 항목                  | 결정                                                                       |
| --------------------- | -------------------------------------------------------------------------- |
| 필터 진입점           | **사이드바 상단 태그 칩 목록** (토글). 기존 `Chip` 컴포넌트 재사용         |
| 다중 선택 의미        | **OR** — 선택 태그 중 하나라도 가진 노트 표시                              |
| 필터 상태 위치        | **`App.tsx` UI 상태**(useState, 비영구). 새로고침 시 초기화                |
| 선택 가능한 태그 목록 | **현재 `notes`의 태그 합집합**(중복 제거). 별도 저장 없음                  |
| 빈 결과               | 결과 0개면 **"해당 태그의 노트가 없습니다" 안내 + 필터 해제 버튼** 제공    |
| 태그 없는 노트        | 필터가 켜져 있으면 **목록에서 숨김** (어떤 선택 태그도 없으므로 OR 불일치) |

## 경계 조건

- 노트가 0개거나 어떤 노트에도 태그가 없으면 → **칩 목록 자체를 렌더하지 않음**(필터 UI 없음).
- 켜진 태그를 가진 노트가 모두 삭제되어 결과가 0개가 되면 → 빈 결과 안내 + 해제 버튼.
- 현재 선택된 노트(에디터에 열린 노트)가 필터로 목록에서 숨겨져도 → **선택/에디터 상태는 건드리지 않음**(목록 가시성과 선택 상태는 독립).

## 에러 처리

- 필터는 순수 클라이언트 인메모리 연산이라 **새로운 API 호출·에러 경로가 없다.**
- 기존 `NoteList`의 loading/error/empty early-return은 그대로 유지하고, 그 이후 단계에 필터를 얹는다.

## 성능

- 노트 수가 적은 실습 앱 규모. 매 렌더 `notes.filter`로 충분(메모이제이션은 선택적, 과한 최적화 지양).

## 기존 UI 패턴 재사용

- 태그 칩 시각화는 **`Chip` 컴포넌트** 재사용(Sanctuary Archive 디자인 시스템 준수).
- 상태 3계층 분리 유지: 필터는 **UI 상태**이므로 `App.tsx`에 둔다(NotesContext에 넣지 않음).

## Out of Scope (이번 범위 아님 — 단계 2에서 확정)

- AND 조합, 태그 검색/입력형 필터, 텍스트 검색과의 결합.
- 필터 상태 영구화(localStorage·URL 쿼리).
- 별도 고정 태그 사전(taxonomy) 관리.

## 용어 정의 (Ubiquitous Language)

- **필터 칩(Filter Chip)**: 사이드바 상단에 표시되는, 토글 가능한 태그 버튼.
- **켜진 태그(Active Tag)**: 현재 선택되어 필터에 적용 중인 태그.
- **필터 상태(Filter State)**: 켜진 태그들의 집합. `App.tsx`의 UI 상태.
- **태그 합집합(Tag Universe)**: 현재 모든 노트의 태그를 중복 제거한 전체 집합 = 필터 칩 목록의 출처.
- **보이는 노트(Visible Notes)**: 필터 적용 후 목록에 렌더되는 노트.
