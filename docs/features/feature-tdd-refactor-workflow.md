/skill-creator를 사용해서 아래 조건으로 .claude/skills/tdd-refactor/SKILL.md를 만들어줘:

목적: 테스트 통과 상태를 유지하면서 코드 구조를 개선 (TDD Refactor 단계)

실행 순서:

1. CLAUDE.md 읽기 → 프로젝트별 컨벤션(네이밍, 패턴, 스타일링) 파악
2. npm test 실행 → 전체 통과 확인부터 시작
3. 리팩토링 대상 파일 식별
   - git diff main...HEAD --name-only -- src/로 이번 이슈에서 변경된 src/ 내 파일 목록 추출
   - 테스트 파일(\*.test.ts/tsx) 제외
   - 남은 파일에 대해 아래 범용 점검 기준으로 검토
     범용 점검 기준 (스킬 내장):
     - 중복 제거: 같은 로직이 반복되는가
     - 네이밍 명확성: 의도를 드러내는 이름인가
     - 단일 책임: 하나의 함수/컴포넌트가 너무 많은 일을 하는가
     - 불필요한 복잡도: 매직 넘버, 과도한 중첩, 불필요한 추상화
     - CLAUDE.md 컨벤션 불일치: 프로젝트 패턴과 어긋나는 코드
4. 리팩토링 대상 목록을 개발자에게 보고 → 승인 대기
5. 하나의 변경 → npm test → 통과 확인 → 다음
6. 테스트가 깨지면 즉시 롤백 후 다른 접근
7. 리팩토링 전후 변경 요약 제공

제약:

- 새 기능 추가 금지
- 테스트 파일 수정 금지
- src/ 디렉토리 밖 수정 금지
- 대상 파일 범위(git diff 결과) 밖 수정 금지
- 입력: 이슈 번호 ($ARGUMENTS)
