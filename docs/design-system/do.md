# ✅ Do — Sanctuary Archive

스타일 작업 완료 후 이 체크리스트로 자가 리뷰한다.

## 타이포그래피

- [ ] 헤드라인은 **Playfair Display**, 본문·라벨은 **Source Serif 4**를 쓴다.
- [ ] 폰트 스택에 **한글 세리프 폴백(Noto Serif KR)** 을 포함한다.
- [ ] 라벨/메타는 small-caps 또는 **이탤릭**으로 기록보관소 표기 느낌을 준다.
- [ ] 타입 레벨([tokens.md](./tokens.md))의 크기/굵기/행간을 그대로 쓴다.

## 색상

- [ ] 배경은 따뜻한 양피지(`#fef8f5`)를 베이스로 한다.
- [ ] 텍스트는 잉크 블랙(`#1d1b19`)을 쓴다 (순수 검정 아님).
- [ ] Primary(Deep Leather `#322214`)는 **핵심 액션(저장/생성 등)에만** 쓴다.
- [ ] 액센트는 Aged Brass/Tan(`secondary`), Dusty Vellum(`tertiary`) 어스톤으로 제한한다.
- [ ] 임의 HEX 대신 [tokens.md](./tokens.md)의 토큰/시맨틱 클래스를 쓴다.

## 깊이 & 그림자

- [ ] 깊이는 **톤 레이어**(`surface-container-*` 스케일)로 표현한다.
- [ ] 인풋·보조 컨테이너는 **inner-shadow 음각**으로 종이에 눌린 느낌을 준다.
- [ ] 버튼 그림자는 **hard-edge 2px**(`2px 2px 0 0`)로 카드스톡 두께를 표현한다.

## 모서리 & 형태

- [ ] 모서리는 **soft 4px**(`DEFAULT`)를 기본으로, 최대 12px(`xl`)까지만 쓴다.
- [ ] 칩은 `full`(pill) + 이탤릭 + 좌측 punch-hole 아이콘.
- [ ] 카드는 1px 외곽선(`outline-variant`) 또는 톤 시프트로 정의한다.
- [ ] 인풋은 하단 룰 라인(공책 줄) 또는 옅은 음각 박스로 만든다.

## 레이아웃

- [ ] 콘텐츠는 화면 중앙 정렬, 최대 1120px.
- [ ] 데스크탑 64px / 모바일 20px 여백을 둬 "프레임" 효과를 준다.
- [ ] 양피지에 **항상 보이는 가장자리/인셋**을 남겨 "종이 오브젝트" 은유를 유지한다.
- [ ] 8px baseline grid로 수직 리듬을 맞춘다.

## 디테일

- [ ] 주요 섹션 구분에만 장식 플로리시(◆)를 쓴다.
- [ ] 리스트 구분 룰은 컨테이너 가장자리에 닿지 않게 한다(ledger 느낌).
