# List — Sanctuary Archive

토큰: [../tokens/color.md](../tokens/color.md), [../tokens/spacing.md](../tokens/spacing.md).

- 행은 넉넉한 세로 패딩(`stack-sm`~`stack-md`).
- 구분은 **컨테이너 가장자리에 닿지 않는** 얇고 우아한 가로 룰(`outline-variant`) — 장부(ledger) 느낌. 또는 여백만으로 구분.
- 가장자리까지 꽉 찬 구분선 금지([../dont.md](../dont.md)).

```html
<ul>
  <li class="py-stack-sm">…</li>
  <li class="py-stack-sm border-t border-outline-variant mx-stack-sm">…</li>
</ul>
```
