# Principles — Sanctuary Archive

## 브랜드 & 무드

**Sophisticated Traditionalism** — 디지털 저장소이지만 물리적 유산(가죽 장정 저널, 기록 보관소)처럼 느껴지는 인터페이스. 고급 문구류와 양피지의 촉각적 무게감을 디지털로 옮긴다.

- **성격**: 권위 있고, 시간을 초월하며, 지적이다. "Sanctuary Archive(성역 기록보관소)".
- **대상**: 작가·연구자·전문가 — 방해 없이 사고하고 기록할 "digital zen" 환경.
- **정서**: 조용한 자신감 — 넉넉한 여백, 고품질 타이포그래피, "두꺼운" 물성.
- **콘텐츠가 주인공**: UI는 콘텐츠를 떠받치는 조용한 조력자. 시끄러운 색·과한 애니메이션을 쓰지 않는다.

## 4대 원칙

1. **Editorial Serif**
   헤드라인은 Playfair Display(고대비·우아한 masthead), 본문/라벨은 Source Serif 4(가독·학술적). 산세리프는 쓰지 않는다. 라벨·메타는 small-caps/이탤릭으로 기록보관소 표기 느낌. → [tokens/typography.md](./tokens/typography.md)

2. **Warm Parchment**
   차가운 그레이가 아니라 따뜻한 양피지/잉크/가죽/황동 어스톤. 베이스는 양피지 `#fef8f5`, 텍스트는 잉크 `#1d1b19`(순수 검정 회피), 순백 글레어는 최상층 컨테이너에서만. → [tokens/color.md](./tokens/color.md)

3. **Tonal & Letterpress Depth**
   떠 있는 흐릿한 그림자 대신 **톤 레이어**(표면 스택) + **음각(letterpress, inner-shadow)** + 버튼의 **hard-edge 2px 마이크로 그림자**. 큰 blur 금지. → [tokens/elevation.md](./tokens/elevation.md)

4. **Analog Object**
   화면을 "책상 위에 펼친 책"처럼. 중앙 정렬, 넉넉한 여백 프레임(데스크탑 64px / 모바일 20px)을 항상 유지해 "종이 오브젝트" 은유를 지킨다. → [tokens/spacing.md](./tokens/spacing.md)
